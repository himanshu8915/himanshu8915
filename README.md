### LLM Cost Engineering

The question I'm exploring:

> **How can we make capable AI systems significantly cheaper without
> blindly sacrificing quality?**

Current work:

-   🔀 **LLM routing & model cascades**
-   💰 **Inference and token-cost optimization**
-   📊 **Quality / cost / latency evaluation**
-   🧠 **RAG and retrieval optimization**
-   🤖 **Production-grade agentic systems**
-   🧪 **LLM evaluation and reliability**
-   ⚡ **Latency and inference optimization**

Rather than sending every request to the strongest model, I am
interested in systems that dynamically decide:

**which model to use · how much context to retrieve · which tools to
call · how much computation is necessary**

### 🧾 Chargeback AI

**FastAPI · LangGraph · LangChain · Gemini · PostgreSQL · pgvector ·
BM25 · RRF · Docker**

Evidence-driven chargeback analysis combining structured evidence
retrieval with agentic reasoning.

-   Hybrid BM25 + vector retrieval
-   Reciprocal Rank Fusion
-   SQL-based evidence retrieval
-   Contradiction detection
-   Deterministic risk / economic analysis
-   Agent orchestration and API architecture

------------------------------------------------------------------------

### 🫀 AI4CAD

**PyTorch · YOLOv8 · DICOM · Grad-CAM · LangGraph · LangChain ·
MedGemma**

Agentic coronary angiography analysis combining computer vision with
LLM-based reasoning.

**Result:** reduced AI-assisted analysis time from **20--40 minutes to
\<5 minutes**.

------------------------------------------------------------------------

### 🩻 Radiology OpenEnv

**Python · Reinforcement Learning · OpenEnv · FastAPI · Docker · LLM
Agents**

An OpenEnv-compatible environment for sequential radiology agents.

Agents perform region exploration, disease prediction, adaptive
stopping, and sequential diagnostic decision-making with dense reward
evaluation.
